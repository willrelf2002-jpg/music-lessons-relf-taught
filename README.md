# Will Relf Music Website

A complete responsive one-page website for piano/drum lessons and session musician work.

## Files Included
- `index.html` — Updated website HTML
- `style.css` — Modern design and responsive CSS layout
- `script.js` — Interactive scripts for mobile navigation, review modal popups, and form submission handling
- `PHOTO-2026-09-27-12-21-59.jpg` — Correctly rotated hero section portrait photo

## Deployment to GitHub Pages
1. Extract this ZIP file.
2. Push all files to a repository on GitHub.
3. Enable GitHub Pages in repository settings (`Settings > Pages > Branch: main`).
